# Hi, I'm Ellie

Ph.D. candidate in Computer Science at Virginia Tech, graduating December 2026.
I build XR systems that adapt to the person using them.

My research sits where **psychophysics**, **XR systems engineering**, and **adaptive environments** meet: I run controlled perceptual studies, then turn what they show into working software on real hardware.

## Current work

- **[MAX — Multimodal Adaptive XR](https://github.com/el-mhmdrzee/MAX)** · Closed-loop personalization of XR environments from task performance and physiology. First modality: adaptive lighting on Apple Vision Pro. *Dissertation.*
- **[WeightWeSee](https://github.com/el-mhmdrzee/WeightWeSee)** · Can visual cues alone make a virtual object feel heavy? A Vision Pro experiment measuring reaching kinematics under visual-only weight manipulation.
